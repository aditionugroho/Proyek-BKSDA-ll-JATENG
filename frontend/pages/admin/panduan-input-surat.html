Panduan Input Surat

SOP • RIWAYAT AKTIVITAS

Prosedur baku pendaftaran naskah dinas pada sistem e-Office SKSDA Wilayah II Pemalang, beserta riwayat aktivitas input surat oleh petugas.

Input Surat Masuk Input Surat Keluar

Alur Umum Pendaftaran Naskah Dinas

Berlaku untuk seluruh surat masuk dan keluar sebelum didistribusikan

  1. 1

    Pemeriksaan Berkas Fisik

    Pastikan naskah lengkap: kop, nomor, tanggal, isi, dan tanda tangan pengirim terbaca jelas.

  2. 2

    Pemindaian (Scan)

    Scan berwarna format PDF, ukuran maksimal 5 MB, satu file per naskah.

  3. 3

    Registrasi di Sistem

    Isi formulir melalui menu Input Surat — nomor agenda dan tanggal tercatat otomatis oleh sistem.

  4. 4

    Unggah & Verifikasi

    Lampirkan hasil scan, periksa ulang isian, lalu simpan. Data masuk ke daftar distribusi Kepala Seksi.

Surat Masuk

Naskah dari instansi eksternal / internal lain

  • Pilih menu Input Surat → Registrasi Surat Masuk.
  • Isi tanggal penerimaan sesuai stempel tanda terima (bukan tanggal surat dibuat).
  • Cantumkan nomor surat pengirim apa adanya, termasuk kode instansi.
  • Isi pengirim, perihal, dan sifat (Biasa / Penting / Segera / Rahasia).
  • Nomor agenda sekensi tahun berjalan ter-generate otomatis — jangan menginput manual.
  • Setelah tersimpan, naskah otomatis masuk daftar disposisi Kepala Seksi.

Surat Keluar

Naskah resmi yang diterbitkan sekretariat

  • Pilih menu Input Surat → Registrasi Surat Keluar.
  • Pastikan naskah sudah diperiksa dan diparaf Kepala Seksi sebelum didaftarkan.
  • Isi tujuan surat (instansi/alamat) secara lengkap untuk kebutuhan ekspedisi.
  • Nomor surat berformat KODE/BLN/TAHUN diberikan sistem — cek jangan sampai ganda.
  • Lampirkan draf final (PDF), bukan berkas kerja (DOCX).
  • Setelah dikirim, catat nomor ekspedisi pada kolom keterangan bila menggunakan jasa pos.

Yang Wajib Dilakukan

  • Input surat paling lambat 1×24 jam sejak diterima/diterbitkan.
  • Gunakan nama file yang bermakna: NomorAgenda_Tanggal_Perinjal.pdf.
  • Cek klasifikasi kerahasiaan sebelum menyimpan — salah klasifikasi berdampak pada hak akses pembaca.
  • Segera laporkan ke admin bila menemukan input ganda.

Yang Tidak Boleh

  • Jangan menunda scan — berkas fisik mudah tercecer di meja agenda.
  • Jangan mengubah nomor agenda/naskah yang sudah tersimpan; minta admin koreksi.
  • Jangan unggah foto kamera miring/kurang terang sebagai pengganti scan.
  • Jangan membagikan akun untuk input bersama — riwayat akan tercampur antar petugas.
